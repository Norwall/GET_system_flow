# Primary Source Drop Directory

Place full primary-source PDFs or archival scans in `sources/primary/` when
releasing a source-gated published model.

Rules:

- Do not commit PDFs, scans, or extracted full text from this directory.
- Record each local file in `docs/primary_source_inventory.md` before using it
  for formula transcription.
- A source-gate release must include the local filename, SHA256 hash, citation,
  audited page/equation references, audit decision, formula-registry update, and
  reference tests.
- DOI pages, abstracts, metadata records, repository landing pages, textbooks,
  reviews, or formula summaries are not sufficient release evidence.

This README is tracked only to keep the expected local directory in the repo.
